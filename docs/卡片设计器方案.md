# 卡片设计器方案

> 目标：让用户自己设计仪表盘卡片。产物是**代码卡**（html/css/js），交互参考
> Canva/稿定（模板画廊 + 图标轨 + 弹出面板），支持上传/绘制背景、添加实体并控制、
> AI 设计，规范由项目内单一来源 `cardSpec.md` 驱动（IDE 技能与 AI 调用同源）。

## 总体架构

```
模板画廊 TemplateGallery ──套模板──► 设计器 Designer ──保存──► 卡片（代码）
              ▲                        │
              │我的模板                 ├─ 画布 Canvas（Moveable 拖拽/缩放/旋转 + vue3-guides 标尺）
              │                        ├─ SideRail + FlyoutPanel（素材/文字/实体/AI/代码）
       空白画布/AI 入口                 ├─ 右侧：选中=属性面板；未选中=画布设置（尺寸/背景）
              │                        └─ LivePreview 全屏预览（真实实体数据）
              │
AI 设计 AiPanel ──/api/v1/ai/chat（后端注入 key 转发 OpenAI 兼容接口）──► parseAiSchema ──► loadSchema
```

- 设计态统一操作 **schema v2** 结构化 JSON；保存时编译为代码并允许手改覆盖。
- 画布预览、模板缩略图、实时预览、最终产物**共用同一渲染器**（所见即所得）。

## schema v2 与渲染管线

```json
{ "version": 2, "canvas": { "w": 480, "h": 240, "background": {} }, "elements": [] }
```

- 设计基准 1 格 = 120px；元素绝对定位（x/y/w/h/rotate + props），数组顺序 = 图层 z 序。
- `elementDefs.js` 的 `renderElementsToHtml` 编译产物全部用 `cqw/cqh` 容器查询单位
  （根容器 `.hc` 带 `container-type: size`），卡片在任意格宽下整体等比缩放。
- 元素类型注册表 `ELEMENT_DEFS`：text / icon / image / rect / entity / button，
  `propsSchema` 声明式驱动属性面板（FormKit）。新增类型 = 注册表 + `renderInner` 分支。
- 运行时由 `CodeCard.vue` 渲染：`v-html` + `{{占位符}}` 注入 + data-hc 事件委托。
  - 实体元素编译占槽位 i，产物输出 `{{s_entity_ids_<i>_icon|name|state|unit}}`，
    实体 id 收集进 `entitySlotMap.entity_ids`，运行时 `bindingSlotTokens` 注入实时值。
  - 交互：`data-hc="toggle|svc|link|range|select"`，内置乐观更新与 1s 防连点，
    产物禁止自写 onclick / 轮询。

## 画布背景（上传或画）

`canvas.background` 三选一，编译时内联到 `.hc` 根容器 style
（`canvasBackgroundStyle`，优先级高于壳层样式）：

| type | 字段 | 说明 |
|---|---|---|
| `color` | color | 纯色，CSS 值/变量（「画」背景：取色器 + 文本框） |
| `gradient` | from / to / angle | 线性渐变，angle 缺省 135 |
| `image` | image / fit(cover\|contain) | 本地上传转 dataURL（限 800KB，双端随 prefs 同步）或 http(s) URL |

- 入口：设计器右侧「画布设置」（无选中时）。素材 flyout 另有「上传图片」生成图片元素。
- 上传工具：`designer/imageUpload.js` 的 `pickImageFile`（背景与图片元素共用）。
- AI 产出的图片背景仅允许 http(s)（`parseAiSchema` 白名单，防 data:/js 注入）。
- 无背景 = 省略字段，用壳层默认底色。

## 实体添加与控制

- 「实体」flyout 一键添加：**实体状态**（实时注入图标/名称/状态/单位）与
  **按钮**（action=toggle 开关实体 / link 跳转），属性面板用 entity-select 绑定。
- 点击动作编译为 data-hc 协议属性，运行时由 CodeCard 委托处理。

## 模板体系

- **首屏模板画廊**（TemplateGallery）：12 个精品内置模板（`templates/catalog.js`），
  分类筛选 + 「我的模板」+ 空白画布/AI 设计入口。
- **角色槽绑定**：模板声明 `roles`（domains/必填/mock 数据），元素挂 `props.role`
  而非硬编码实体；套用弹 RoleBindDialog 映射到真实实体（`designerStore.applyTemplate`）。
- 缩略图用 mock 实体（`mockEntities.js`）经同一渲染器生成，与实物观感一致。
- 用户模板存 `_designerSchema` + `_roles`，保存卡片自动带角色信息，可再次编辑/再模板化。

## 编辑器交互（Canva 风格）

- 左：54px 图标轨（模板/AI/素材/文字/实体/代码）+ 280px flyout。
- 中：画布缩放 25%–200%（外层 `transform:scale` + Moveable `:zoom`，不改 DOM 尺寸），
  vue3-guides 标尺随滚动/缩放同步，底部悬浮缩放工具条；Delete/方向键/Ctrl+Z/Y 快捷键。
- 右：上下文面板（选中=元素属性；未选中=画布尺寸/背景设置）+ 可折叠图层抽屉。
- 顶栏：返回 / 撤销重做 / 全屏实时预览（可选格数尺寸）/ 保存。
- 代码 flyout（Monaco）：手改 html/css/js 覆盖优先于编译产物，代码不丢。

## AI 设计

- 配置：`user_prefs.ai_config = { base_url, api_key, model }`（OpenAI 兼容）；
  GET 不回传明文 key（只回 has_key），PUT 时空 key 保留原值。
- 后端 `POST /api/v1/ai/chat`：读取用户配置、注入 Bearer key、转发 chat/completions
  （55s 超时，消息 32KB / 响应 1MB 上限，上游错误转 502）。
- 前端 AiPanel：描述 + 勾选实体 → `buildSystemPrompt` → 模型输出纯 JSON →
  `parseAiSchema` 容错（围栏提取、类型过滤、越界收敛、id 去重、背景白名单）→ 落画布微调。

## 规范单一来源（技能 × AI 调用）

- **`app/src/components/cards/designer/cardSpec.md` 是唯一规范源**（git 跟踪）：
  渲染管线、schema v2、背景、元素表、占位符、data-hc、CSS 变量、设计质量。
- IDE 技能 `.trae/skills/hc-card-dev/SKILL.md` 是指针（保留代理流程/校验清单）；
  `.gitignore` 加例外 `!.trae/skills/` 使其入库，`.trae` 其余内容仍忽略。
- AI 调用 `aiPrompt.js` 用 `import cardSpec from './cardSpec.md?raw'` 原样内嵌系统提示词，
  并附 `ELEMENT_DEFS` 实时生成的 props 清单（标注「以此为准」）。
- **改规范只改 cardSpec.md**，技能与 AI 设计同步生效。
