## v1.6.0（2026-10-20）

### 卡片设计器 · 变成可视化低代码搭建

卡片编辑里的「设计」模式从「选中元素改样式」升级为可拖拽搭建：

- **组件库**：新增「组件」页，内置文字、大数字、说明文字、图标、徽章、胶囊标签、状态圆点、面板底衬、分隔线、进度条、图标按钮，以及「实体名称 / 当前数值 / 状态文案」三个跟随 HA 实体数据自动刷新的数据控件；点按即插入到卡片中央，电脑上还可直接拖到画布指定位置松手
- **拖动摆放增强**：拖动元素时靠近卡片边缘或其它元素边线会自动吸附，并显示橙色对齐参考线；按住 <kbd>Alt</kbd> 可临时关闭吸附；拖动过程中显示坐标与尺寸徽章
- **键盘微调**：选中元素后方向键移动 1px，<kbd>Shift</kbd>+方向键移动 10px
- **拖角缩放**：选中元素后边框出现 8 个方块手柄，拖动即可改宽高（<kbd>Shift</kbd> 拖动角柄等比缩放）
- **图层顺序**：新增「图层」页，可视化查看卡片元素树、点击即选中；支持置顶/置底/上移/下移，电脑上还可拖动行调整同一容器内的顺序
- 属性条新增「复位位置/尺寸」（回到元素原始布局），帮助提示与操作引导同步更新

### 自定义卡 & 用户模板

- 新增内置 **自定义** 卡（1×1 空白起步，`needEntity=false`），在添加面板分组「自定义」里出现；点「添加」后立即打开卡片工作室并自动进入图形化设计模式、右侧默认跳到「组件」页
- 卡片工作室顶栏新增 **「保存为模板」** 按钮：把当前这张卡（无论是从 custom 空卡搭起还是改好的某张已有卡）注册成用户自己的模板；输入模板名、图标、是否绑定实体即可；同名模板会覆盖（以后再改一次就能更新）
- 模板持久化在 `user_prefs.card_templates`（双端同账号共享），启动时热注入进卡片类型注册表，下次点「添加卡片」就能在分组「我的模板」里找到，点进去直接克隆一张一模一样的卡并进入编辑
- 添加面板里每张用户模板自带一个删除按钮（右上 ×），只对模板可见；已用模板创建的卡不受影响（模板类型从注册表移除后，再次打开该卡会被 normalizeCards 丢弃，属预期行为）

### 修复

- 修复删除元素后再插入新元素会出现元素身份（data-vid）重复、导致选中与删除错乱的问题
- 修复同一元素第二次拖动时幽灵副本起手位置跳变、与手指偏移的问题

## v1.4.4（2026-10-14）

### 地图 · 路线规划与到家距离

- **路线规划**：地图页新增「路线」入口，支持驾车 / 骑行 / 公交 / 步行四种方式；以当前位置为起点、家为终点（也可在地图上点选终点），画出路线并显示距离与预计耗时
- **到家距离传感器**（被动）：APP 上报位置时自动计算当前位置到家的直线距离，在 Home Assistant 中自动生成「XX 到家距离」传感器（单位 km）；移动超过 500 米才重新计算，位置不变每 2 小时刷新一次，可直接用于「距家 >X 公里提醒」「接近家自动开灯」等自动化
- **修复后台定位不触发回家自动化**：此前 APP 退后台后位置上报链路被系统冻结，回家触发要等到下次打开 APP；现改为原生后台直接上报设备位置（device_tracker），回程途中即可触发回家 / 离家自动化
- **修复在家规划路线误触发离家自动化**：路线规划起点定位按端区分——APP 端原生卫星定位精度高，定位即上报 HA；Web 端浏览器定位精度差（Wi-Fi 级常漂出家门范围），仅取坐标用于画线、不上报

### 消息与通话

- **修复 APP 后台时间久了通话显示对方离线**：WebView 退后台后页面心跳定时器被冻结，WebSocket 无法发心跳/断线重连，服务端超时注销连接；现由原生后台心跳每 60 秒驱动页面发送心跳帧，连接断开时立即重建，后台保持实时在线，来电不再误判离线

### 界面修复

- 修复设置页「消息免打扰」卡片在窄卡内文字竖排的问题
- 修复手机端仪表盘拖拽：卡片拖到某排行尾的空白处现在也能正常插入
- 修复手机端进入编辑模式后看不到「添加卡片」入口：编辑操作栏此前被底部 Tab 栏遮挡，现进入编辑态自动隐藏 Tab 栏；手机端保持「长按卡片进入编辑」手势，非编辑态不再显示编辑按钮

## v1.4.3（2026-10-14）

### 智家助手 · 语音朗读

- **修复「朗读失败：内置 Edge TTS、服务端 TTS、系统 TTS 均不可用」**：微软于 2026-10-10 更换了免费 Edge TTS 在线接口的鉴权算法，导致「内置 Edge TTS」与「服务端 TTS」两条路线同时被拒（403）。本次已将 APP 内置与服务端同步升级到新鉴权（v2 DRM token），在线朗读恢复可用，音色不变
- 系统语音路线不受本次微软变更影响；若此前系统 TTS 在个别机型上不可用，在线引擎恢复后朗读将优先走在线路线

## v1.4.1（2026-10-14）

### 智家助手 · 语音朗读

- **切换即试听**：在会话顶部切换「朗读引擎」后立即试读一句测试语音，切换是否生效当场可闻，无需再发消息验证
- **失败不再无声**：所有朗读路线（内置 Edge TTS → 服务端 → 系统语音）都失败时，会明确提示具体哪些引擎不可用，便于排查网络或系统 TTS 问题
- **修复国产手机系统语音静默失败**：部分 ROM 默认 TTS 引擎初始化失败或缺中文语音时原来无声无息，现在系统语音不可用会自动落到在线引擎朗读

### 首页仪表盘

- **列数可自定义**：设置 → 个性化 → 仪表盘列数，可选「自动 / 2~6 列」；该设置仅对本设备生效，手机设 3 列、平板设 5 列互不影响
- **跨机型显示一致**：不同品牌手机（屏幕密度、「显示大小」设置不同）不再出现一台 3 列、一台 2 列的差异，窄屏统一 3 列，卡片自动等比缩放
- **修复卡片边框叠线**：卡片边框不再出现贴边暗带、角部弦线等多余线条

### 界面细节

- 页面操作提示改为**悬浮抽屉**：从页头下方滑出、数秒自动收起，不再挤压页面内容
- 手机端仪表盘**编辑工具条**（导出/导入/智能排版/重置/完成）单行排列，不再换行占两行
- 户型图编辑模式提示悬浮化，不占画布空间、不干扰绘制操作

## v1.4.0（2026-10-14）

### 传感器 · 原生统一采集

- **APP 内所有传感器数据改由安卓原生采集并直连服务器上报**：退后台、锁屏、切换应用都不中断（与官方 Home Assistant App 同源思路），纯浏览器环境仍走浏览器采集
- 新增传感器项支持：电池、网络、Wi-Fi、环境光、接近感应、位置（含逆地理地址）、公网 IP 等（开发规范见 [传感器原生采集开发规范](传感器原生采集开发规范.md)）
- 后台定位权限引导：位置类传感器后台刷新需将定位权限设为「始终允许」，设置页一键跳转

### 仪表盘

- **布局按 Web / APK 双端分开存储**：同一账号在电脑浏览器和手机 APP 可各自维护一套仪表盘布局，互不覆盖

## v1.2.0（2026-10-13）

### 传感器 · 后台实时上报

- **APP 退后台后传感器仍按间隔实时上报**：常驻保活服务以原生心跳驱动采集，WebView 冻结定时器也不影响
- **上报间隔可配置**：设置 → 连接与设备 → 设备传感器，10 秒 ~ 1 小时可选（与官方 App 类似）

### 稳定性

- **程序被杀自动恢复**：常驻服务被系统清理后自动重启并拉起主界面，恢复连接与上报
- **开机自启动**：手机重启后自动恢复常驻服务（小米等国产系统需在系统设置中允许「自启动」）
