01 / Overview

设计主张：设置不是后台，是账本的「后台页」

记账页面的性格是「低饱和暖灰底 + 单点琥珀强调 + 大字号金额」。设置页不再用密集表单，而是沿用同一套分组卡与行式结构，把 15 个功能模块收敛成 5 个分组、两级导航，让页面在 6 英寸屏幕上一屏可扫读。

03 / Layout

三层结构：大标题 → 分组导航 → 分组卡

沿用现有设置页已验证的「分组 + 页内二级」模型，但把导航信息量压缩：一级只保留 5 个分组，二级改为分段控件与 chips，纵向空间还给内容。

区域内容行为高度
01 页头「设置」21px 大标题 + 当前分组面包屑 + 版本号随页面滚出，不吸顶~52px
02 分组导航连接 / 智能 / 设备 / 外观 / 账户（带 14px 图标）吸顶；左右可横滑；选中项琥珀底44px
03 二级切换仅当分组含多页时出现：分段控件（AI / 诊断 / 日志）切换不滚动页面，保留滚动位置36px
04 页内锚点区块 chips（模型 / 阈值 / 提示词）横滑；点击平滑滚动到卡30px（随内容滚走）
05 内容分组卡列表，卡间距 12px纵向滚动，卡片可整体点击自适应
06 底部操作条保存 / 重置；危险操作单独成卡仅在表单页出现，避让安全区44px + 安全区

05 / Interaction

反馈要「快、轻、确定」

设置页的交互目标是减少不确定性：点下去有回弹、开关有位移、保存有落点、危险操作有二次确认。全部动效 ≤ 200ms，避免拖慢操作。

事件反馈时长 / 曲线实现要点
行/按钮按下整体缩放至 0.97 + 轻微降亮120ms / ease-out:active 或 @pointerdown；抬起立即复原
开关切换轨道换色 + 拇指弹性位移180ms / cubic-bezier(.22,.61,.36,1)不做全屏 toast；APK 内触发一次轻震动
分段/色卡切换指示块滑动 / 描边高亮，内容即时预览180ms不等接口，先本地乐观更新
分组切换标题与面包屑淡入，内容区 80ms 交叉淡出160ms保留各分组滚动位置（keep-alive / 缓存 scrollTop）
保存成功底部按钮短暂变「✓ 已保存」+ 顶部细条 toast2s 自动消失失败则原地展开红字原因 + 重试按钮
危险操作底部抽屉二次确认（标题 + 后果 + 取消/确认）抽屉 240ms确认按钮默认非主色，需明确点选；危险文案用 --c-error
长任务（连接测试）行尾状态点呼吸 + 文案「检测中…」循环 1.2s完成后切换成功/警告/失败三态并保持结果

状态设计

  • 加载：分组卡骨架（surface 底 + 12px 圆角占位条），不使用全屏转圈。
  • 空：设备/用户为空时整卡显示一枚线性图标 + 一句引导 + 主按钮，不保留空白行。
  • 错误：行内红字说明 + retry，仅影响当前卡，不弹全局弹窗。
  • 禁用：透明度 0.45、禁用点击、保留说明文字（例如无管理员权限时的 HA 连接卡）。
  • 权限：无记账权限的用户不渲染账户卡中的授权区；接口 403 时前端兜底隐藏并提示联系管理员。

06 / Adaptation

375–430px 一套布局，单手可达

不按设备写死断点：边距固定 16px，内容自适应；主要操作落在拇指热区（屏幕下半部），顶部只承担导航与浏览。

项目规则
宽度375 / 390 / 414 / 430px 均使用 16px 页边距、12px 卡间距；卡片宽度 = 100% - 32px
最小触控所有可点元素命中区 ≥ 44×44px（视觉可更小，用 padding 补足）
安全区底部 padding-bottom: calc(16px + env(safe-area-inset-bottom))；吸顶导航 padding-top 计入状态栏
单手热区保存/新增等主操作固定在屏幕底部 1/3；顶部仅放导航与只读信息
滚动整页纵向滚动；分组导航与页内 chips 各自横向滚，隐藏滚动条
字号缩放复用现有「字体大小」设置：0.9 / 1.0 / 1.15 三档，作用于正文字号与行高，标题不变
平板/桌面≥1024px 保留现有桌面双栏侧导航；手机样式不溢出到桌面
横屏保持单列，卡片最大宽度 560px 居中，避免超宽行导致阅读跳行
深色/浅色主题所有颜色取自 rgb(var(--c-*))，浅色主题（宣纸）自动生效，无需单独写一套 CSS

07 / Handoff

落地方式：复用现有类，按组件逐步替换

现有设置页已具备 hc-set-* 基座（吸顶、分组卡、分段、chips）。本次不做推倒重写，而是补齐 4 个可复用组件并统一视觉细节。

开发顺序

1. 令牌与组件落地 7 个 settings 组件 + 样式基准，替换现有散落写法
2. 分组结构把 15 个 section 归入「连接/智能/设备/外观/账户」，保持原有接口与状态逻辑不变
3. 页面视效统一标题层级、卡片节奏、图标风格、选中态与状态色
4. 交互补强吸顶跟随、乐观更新、保存反馈、危险操作抽屉、连接自检三态
5. 适配验收375/390/414/430 四档截图比对；单手操作、安全区、键盘顶起、横屏逐项验收
6. 权限联动记账授权行接入新接口；无权限/403 场景隐藏与兜底提示
